# Kadr

Find duplicate and similar photos on your Mac or Windows PC, and keep the sharpest shot.

## Download

- **[Download Kadr for Mac](https://github.com/saidamirabdukakhkhorov-cyber/kadr/releases/download/v0.1.0-beta/Kadr_0.1.0_universal.dmg)**, 7 MB. macOS 11 or later, Apple silicon or Intel.
- **[Download Kadr for Windows](https://github.com/saidamirabdukakhkhorov-cyber/kadr/releases/download/v0.1.0-beta/Kadr_0.1.0_x64_portable.zip)**, 3 MB. Windows 10 or 11, 64-bit.

Then see [Installing the beta](#installing-the-beta) below: the first launch needs one extra click.

## What it does

- **Exact copies**: the same file saved in two places
- **Same photo, other file**: re-saved, resized or sent through WhatsApp or Telegram; the largest original is kept
- **Similar shots**: photos taken seconds apart; the sharpest one is suggested

Nothing is deleted. Photos you set aside move to a `Kadr review` folder next to the originals, and you can undo everything. Emptying that folder is a separate step.

Everything runs on your computer. No account, no upload.

## Installing the beta

The beta builds are not signed yet, so your system will warn you the first time.

- **Mac**: open the `.dmg` and drag Kadr to Applications. If macOS says it can't verify Kadr, open System Settings → Privacy & Security and click **Open Anyway**.
- **Windows**: unzip the folder and run `Kadr.exe`. If you see "Windows protected your PC", click **More info**, then **Run anyway**.

## Known limits

- Kadr works on regular folders, not inside the Apple Photos library.
- On Windows, iPhone HEIC and RAW photos are matched only as exact copies for now.
- The Windows build is brand new. If something breaks, please [open an issue](https://github.com/saidamirabdukakhkhorov-cyber/kadr/issues).
